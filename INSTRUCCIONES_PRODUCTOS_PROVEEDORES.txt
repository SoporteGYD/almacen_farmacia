MODIFICACION: PROVEEDORES EN EL MODULO DE PRODUCTOS
Fecha: 2026-10-09

CAMBIOS
- app/models/Producto.php: la lista de Productos obtiene el proveedor de la
  entrada comercial NO cancelada mas reciente; sin entradas usa el proveedor
  asociado al alta/edicion del catalogo. Ademas permite buscar por proveedor.
- app/controllers/ProductoController.php: valida nombres de proveedor al
  crear o editar productos. El nombre es opcional, 150 caracteres maximos,
  y no permite usar TRASPASO, ENTRADA, AJUSTE u otros conceptos internos.
- public/productos.php: muestra 'Sin proveedor' cuando no existe un proveedor
  comercial vinculado.

REQUISITO
Esta modificacion usa el app/models/Proveedor.php y el
app/helpers/proveedor_historico.php YA REPARADOS en tu sistema. El ZIP completo
incluye las versiones limpias de ambos archivos para no volver a introducir
los conflictos Git que ocasionaron el error HTTP 500.

INSTALACION RECOMENDADA
1. Respaldar codigo y base de datos (especialmente antes de desplegar a Ubuntu).
2. Usar primero el ZIP de solo cambios. Copiar las carpetas app y public al
   proyecto C:/xampp/htdocs/almacen-farmacia conservando las rutas internas.
3. En VS Code, ejecutar (Git Bash):
   /c/xampp/php/php.exe -l app/models/Producto.php
   /c/xampp/php/php.exe -l app/controllers/ProductoController.php
   /c/xampp/php/php.exe -l public/productos.php
4. Revisar git status y git diff. Luego:
   git add app/models/Producto.php app/controllers/ProductoController.php public/productos.php
   git commit -m "Mostrar ultimo proveedor comercial en Productos"
   git push origin main
   Si hay conflictos, resolverlos y comprobar PHP -l antes de subir; no hacer
   git push --force ni copiar marcadores <<<<<<< al proyecto.
5. En Ubuntu Server:
   cd /var/www/almacen-farmacia
   git pull --ff-only origin main
   php -l app/models/Producto.php
   php -l app/controllers/ProductoController.php
   php -l public/productos.php
6. Probar un producto conocido de NADRO/FANASA en Productos y Existencias.
   La tabla deberia mostrar el mismo proveedor comercial.
   Al registrar producto nuevo con proveedor se guarda en productos.proveedor_id
   y en el catalogo proveedores; si aun no registra entradas, ese proveedor se
   muestra cuando el producto cumple los filtros actuales del listado.
   La lista Productos CONSERVA sus filtros actuales de inventario; un producto
   sin stock / ubicacion puede quedar fuera hasta que tenga existencia.

NO SE ALTERAN: saldos de inventario, entradas historicas, costos, folios,
observaciones, traspasos, ni estructura SQL. No se requiere ejecutar el script
recuperar_proveedores_entradas.php para productos nuevos.

VALIDACIONES EN DESARROLLO: sintaxis PHP de todos los modulos no-vendor y
prueba de seleccion de ultimo proveedor con datos sinteticos. No se tiene
conexion a tu BD de Ubuntu; comprobar despues de despliegue.
